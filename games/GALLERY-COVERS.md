# Gallery artwork

The Unblocked Games gallery uses original game icons/cover art or unaltered screenshots captured from the actual locally hosted game. It does not use the old illustrative SVG placeholders.

- Captured locally: Guess the Pokémon (Cry), Guess the Pokémon (Stats), Paper.io 2, Random Trivia, World's Hardest Game, Balloon Bastion, Suika Game, and A Small World Cup.
- Pokémon LeafGreen: original Nintendo box art, https://en.wikipedia.org/wiki/File:Pokemon_LeafGreen_box.jpg .
- Super Mario 64: unaltered title-screen screenshot captured from the locally hosted game using the owner-supplied N64 ROM. The archived NES player retains its original Nintendo NES box art.
- Basket Bros: original `thumb.jpg` from the pinned game source.
- Drift Hunters: original `icon.png` from the pinned game source.
- Other existing raster covers are retained original game art/icons, with upstream sources recorded in the relevant game source notes and IMPORTED-GAMES-SOURCES.md.

Third-party artwork retains its original copyright. The local screenshots show the browser editions actually available in Orbit; a remake is not presented as an official native release.

- Eaglercraft: the black Eagler logo on white requested by the site owner, matching the supplied image. Original raster copied unchanged from https://github.com/Alexx743/Alexx743-games/blob/69a02f9042c8e0c47ed57df3e2384663fdc08ea0/logo%20eaglercraft.jpg .

- Retro Bowl: original pixel quarterback icon matching the owner’s requested cover, copied unchanged from https://github.com/selenite-cc/selenite-old/blob/9c743188888af0986c8c7b293dbac8f9e421a4ee/retrobowl/img/icon.jpg .

- Minecraft 1.5.2 (Browser Port): existing unaltered screenshot of the locally hosted Eaglercraft client (`eaglercraft/cover.jpg`). This is a clearly labeled alternate gallery entry for the same client/world storage, not a different or newer game build.

Gallery backdrop: `chat/unblocked-marble.webp` is a landscape adaptation of the owner-provided blue/silver marbled star-pattern background, created with image editing and encoded as WebP for delivery. Game cover artwork is unchanged. The stationary background and normal scrolling avoid fixed-attachment/parallax effects.

Gallery UI typography uses locally hosted Oxanium for titles and Outfit for descriptive text. Font sources and SIL Open Font License notices are retained under `chat/fonts/`. The gallery’s fullscreen control and hover styling do not alter game artwork.

- Krillion: unchanged official `https://krillion.io/icon.png`, retrieved 2026-11-19. The clearly labeled gallery entry opens the official site in a new tab, respecting its embedding restrictions.
